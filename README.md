# 🏡 Real Estate Application

A full-stack real estate web application where users can browse, list, and manage properties for sale or rent — built with modern web technologies and designed for both end-users and administrators.

---

## 🚀 Features

- Browse property listings: Including images, descriptions, pricing, status (for rent/sale).  
- Add and manage your own property listings (for sellers/agents) with photo uploads.  
- Search & filter by location, price range, property type, number of bedrooms etc.  
- View property details: map location, amenities, contact details.  
- Admin dashboard: Manage users, listings, approve/decline new submissions.  
- Responsive UI for both desktop and mobile.  
- Secure authentication and role-based access (buyer/seller/admin).

## 🧠 How It Works

1. A user visits the website and is presented with a list of available properties.  
2. The user can search or filter listings by criteria (location, price, type).  
3. For each listing, detailed view includes images, description, map and contact info.  
4. Sellers/agents can log in, submit new listings with images and details.  
5. Admin users can review listings, manage user accounts and moderate content.  
6. The backend handles CRUD operations on property listings, user authentication, and data storage.  
7. The frontend interacts with the backend via REST API endpoints and displays dynamic data.
